# Imposteur 0.1

Première version jouable. Jeu de soirée hors-ligne, un seul téléphone que l'on se
passe autour de la table : tout le monde reçoit le même mot secret… sauf les
imposteurs, qui en reçoivent un **très proche**.

## 📲 Installation

1. Télécharge `Imposteur-0.1.apk` ci-dessous.
2. Ouvre le fichier sur ton téléphone Android.
3. Android demandera d'autoriser l'installation depuis cette source — c'est
   normal pour une app qui ne vient pas du Play Store.

Android 7.0 (API 24) minimum. Environ 8 Mo.

## 🎮 Ce que contient cette version

- **3 à 20 joueurs**, un seul appareil, aucune connexion réseau.
- **24 packs de mots**, 2 177 paires (4 354 mots) écrites à la main.
  L'imposteur reçoit toujours le partenaire du mot des civils :
  *Pizza / Quiche*, *Dauphin / Baleine*, *Oslo / Stockholm*.
- **3 modes d'imposteur** : mot proche, thème seulement, ou aucun indice.
- **Révélation carte par carte** : l'écran reste neutre pendant que le
  téléphone circule, la couleur du rôle n'apparaît qu'une fois la carte
  retournée — le joueur précédent ne peut rien deviner.
- **Plusieurs imposteurs** possibles, avec option « ils se connaissent ».
- **Dernière chance** : un imposteur démasqué peut tenter de deviner le mot
  pour voler la manche.
- **Scores de session**, remis à zéro à chaque lancement.
- **43 illustrations vectorielles** dessinées pour l'app : 16 portraits de
  joueurs, 24 icônes de thèmes, 7 icônes d'interface. Aucun emoji système,
  donc un rendu identique sur tous les téléphones.

## ⚠️ À savoir

- L'app est signée avec une clé auto-signée : Android affichera un
  avertissement à l'installation, c'est attendu hors Play Store.
- Aucune permission n'est demandée, aucune donnée ne quitte l'appareil.
